# 后续 Electron 接入边界

当前只提供浏览器 renderer 预览，无 Electron 主进程，也不需要 Node 权限。

后续接入前应先核对现有 Electron 项目的结构与采集端接口，复用已有数据来源，避免另造一套后端。建议通过受限 preload API 将展示数据交给 renderer；不要为了预览关闭隔离、打开任意 Node 调用或暴露凭据。

`src/model.ts` 是最小展示模型，不是采集端协议承诺。适配层需要明确主从团队、平等团队、自研 Agent 身份与子 Agent 的区分，处理断连和重复事件。真实用户请求文本属于项目数据，未接入之前只用演示内容。

可视化渲染器尚未选定。当前 DOM + GIF 足够做素材验证；当布局、动画与性能目标明确后，再评估 Canvas / PixiJS。无需为当前骨架安装 Electron 或新渲染器依赖。
