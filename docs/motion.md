# 视觉生命周期原型

本阶段在现有 DOM 工位上添加 600ms 的短距离入场、换位和退场，不是完整的房间导航或寻路。入场从工位旁标注的门口方向移动，换位使用新的目标工位过渡，离场优先保留在原工位完成；原位被新实例占用或移除时才转入退场区域。同一空位最多保留一个退场轮廓，其余走出口通道。角色始终按实例 ID 唯一管理，工位标识与实例 ID 分开。

## 数据与动画分离

`src/motion.ts` 是纯状态机：

- `reconcileMotion` 使用最新目标覆盖旧目标；同一目标刷新不重启动画。
- 新实例 `arriving → seated`；目标工位变更 `moving → seated`；移除 `leaving → 删除`。
- 快速退场再返回会取消旧退场；epoch 换新不会继承旧实例活动或请求。
- `advanceMotion` 使用帧间经过时间推进，不设置不可取消的完成回调。
- 暂停冻结过渡，**不冻结数据更新和新鲜度**；断线立即降为未知并停止虚构活动。
- 减少动态效果时直接同步到最新工位，无位移过渡。
- 重复实例或重复工位直接拒绝，不能创建同名幽灵角色。

最新用户请求仍取自当前快照，退出中的视觉记录不携带请求内容。拓扑是显式配置，不从运行角色或主机名称推断。

## 素材插槽

`src/motionSlots.ts` 为 idle / active / stopping / unknown / arrival / move / departure 预留动作素材接口。当前只有已确认的待机 GIF 和站姿 PNG：

- idle 可播放已有待机参考；暂停时使用静态站姿。
- 其余状态显示站姿或占位角色，配合状态标记，不假装已有敲键盘动作。
- 入场、移动、退场是**静态图片平移原型**，不是逐帧行走、入座或工作动画。
- 真正动作帧将在用户审阅后单独制作；没有引入任何未批准角色素材。

当前目标是验证生命周期与取消逻辑，而非宣称完成游戏级动画。浏览器视觉与交互仍需要可用运行环境验收；纯状态机、SSR 与 jsdom 挂载交互测试不替代该步骤；挂载覆盖详见 [交互验收](ui-qa.md)。
