# 挂载与浏览器交互检查

本轮在 jsdom 中使用 ReactDOM 挂载真实 `App`，包括 `StrictMode` 和 `useOfficeMotion` 的 effect 生命周期。Vite 的 `ssrLoadModule` 仅用于转换 TypeScript/TSX；断言来自实际挂载后的 DOM，并非仅检查 SSR 字符串。

## 已验证

- 初始挂载与落座；子工位最多三个、`+N` 正确。
- 连续重复点击角色详情；模拟请求与未提供请求保持区分。
- 暂停后使用静态图片、位移冻结且没有剩余帧调度；恢复后离场完成。
- 快速离场/返回、主从/平等布局切换后，最新目标生效，无重复小人。
- 工作中断开连接立即显示未知，重新连接恢复真实适配状态。
- 系统减少动态偏好在运行中切换，按钮与位移行为同步。
- 同一组件实例切换数据适配器，旧订阅被移除，旧角色不遗留。
- 连续 epoch 替换后只保留最新角色；卸载取消订阅、帧回调和媒体监听。

运行 `npm run check` 包含这些测试。本轮总计 48 个测试、3 项素材哈希、TypeScript 和生产构建通过。

## 首轮挂载测试的验收边界

这是 DOM/生命周期测试，不是实际浏览器视觉或 Electron 联调验收。当前详情是常驻检查面板，没有可关闭的弹窗，因此不存在弹窗 Close/Back 流程可测。

尝试使用受支持的云端浏览器访问本地 Vite 预览：本地服务已启动，但浏览器打开 `http://127.0.0.1:4173/` 返回 `net::ERR_CONNECTION_REFUSED`。没有尝试绕过此前独立 Chromium 启动的 socket 权限限制。当时未产生实际页面截图，也未验证 CSS 布局、GIF 播放、真实帧率或 Electron 设备行为；后续同源 staging 浏览器检查见下节。

没有连接真实采集服务、使用凭据或发送模型请求。
