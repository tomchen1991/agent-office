# 完整 Agent 生命周期演示

四个角色可分别选择自己的动作图集。该视图是独立的可回放剧情演示，不是采集端当前状态，也不把真实 `idle` 推断为摸鱼或把未知状态推断为错误。原有多 Agent 视图和接入层保留在另一个标签中。

正常模式按约 26 秒的时间轴自动播放一次：

1. 进场（4 秒）：从左侧入口沿地面路线移动到工位，使用实际行走帧。
2. 坐下（2 秒）：转换到坐姿，角色位于椅子与前桌之间。
3. 工作（6 秒）：坐姿工作动作，配合键盘与屏幕活动。
4. 摸鱼（4.5 秒）：独立休息动作与杯子视觉提示。
5. Error（3.5 秒）：惊讶动作与红色错误屏幕，不使用快速闪烁。
6. 起身（2 秒）：从座位恢复站姿。
7. 退场（4 秒）：反向行走到入口，靠近门时淡出；播放结束停止，不无限循环。

播放/暂停保留当前位置，重新播放从初始时间开始，阶段按钮可直接定位。减少动态效果使用可读的静态动作姿势，不强制持续位移。时间轴是纯函数，渲染调度可取消；切换视图或卸载后不保留旧帧回调。

每个角色包含两张透明 2048×1024 图集，4×2 网格、每格 512×512。locomotion 为四帧走路、两帧坐下、两帧起身；seated 为工作、摸鱼、错误、坐姿待机各两帧。角色分别为紫发双马尾、蓝发鲸尾女仆、白发绿角龙尾、金发哥特小翅膀；不会用紫发素材替代其他角色。

素材清单与 SHA-256 位于 `public/assets/demo/manifest.json`。原有三份自研角色已批准素材保持字节不变；新增图集是按用户完整演示要求生成的动作原型，仍有轻微脸部、衣褶与比例变化，并非原生 48px / 64px 精灵。

代码与挂载测试覆盖四角色各自完整时间线、动作槽、异步加载期间的暂停意图、旧加载回调清理、暂停恢复与减动。真正的空间与动作验收另需在受支持浏览器中逐角色播放，不能仅凭这些自动化测试声明美术验收完成。
