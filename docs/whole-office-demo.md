# 整体办公室动作演示

默认视图把四套已有角色动作接入同一办公室平面；单角色动作检查及接入层数据视图继续单独保留。

## 空间与身份

- 主办公室与公共区域固定共存，不再通过独立 / 主从 / 协作按钮替换家具。
- 主办公室有 1 个大工位及 2 张独立办公桌。自研 Agent 占大工位，模拟子 Agent 使用独立桌，最多展开 2 席，演示其余 3 个显示 `+3`。
- 公共区域有 2 张三人协作桌、10 张独立办公桌及 1 张 GitHub Agent 专属大桌。每席均有椅子、电脑与键盘，空席保留，不播放工作或异常。
- 20 个实体席位中，演示仅有原四角色、新增 GitHub 模拟角色与两个明确模拟子 Actor；未增加虚构身份填满空位。DeepSeek 位于公共协作桌 1，ChatGPT 和 Grok 位于独立工位，展示两类家具同时使用。
- 自研专属身份与任务中的 leader 不同。实际成员的物理席位来自显式配置或已配置成员顺序，不从厂商、主机或 collector role 推断。
- 默认恢复完整场景视图。逻辑画布收紧到 2250×1050，通过压缩行列空隙、调整实际桌椅 / 角色比例提高全景中的可见尺寸，不用相机放大替代布局调整。最新比例修正不再同步放大家具和人物：所有席位的角色独立放大 25%，独立桌与共享桌仅横向收窄 10%（人物相对桌宽提高约 39%），桌面高度不变。椅子与键盘按角色接触点放大，公共协作桌保留三席围坐结构。
- “适应全景”显示完整区域；可选“舒适近景”、100% 及区域定位仍保留，方便细看。缩放、平移和区域跳转都不改变身份、桌数或动作阶段。

## 人物与家具的独立比例

`officeActorWidth` 统一控制整层办公室中的行走、坐下、工作、起身与离场尺寸；`seat.scale` 仍是家具的基础尺度，不改批准的 PNG，也不改独立单角色演示。以 seated anchor 为固定手部接触点放大，脚点和椅子位置同步重算，坐起各边界保持连续。

共享桌只压缩水平空白，三席仍保留左 / 中后 / 右内向布局，左侧整套工位向内移 20px、中间工位右移 20px 保留人物间距、右侧向内移 12px，让放大后的键盘落在桌面内。公共桌局部右移、通道移至 x=780，私室通道为 x=486，门口上缘由 y=750 调到 y=700，给放大后的身高留出通行空间。测试使用实际放大后的 sprite 宽度与批准图集的 alpha 边界检查所有席位、四角色、往返方向、世界边缘和分隔墙，不使用旧尺寸近似。

## 动作与数据边界

同一条 26 秒演示时间轴编排进场、坐下、工作、摸鱼、Error、起身和退场，实际动作发生在各自工位。复用已认可素材与固定脚点坐起修正，提供暂停、重播和阶段选择，遵循减少动态效果偏好。进退场在同一个四秒阶段内按席位错峰释放，避免实例同时挤在入口；整体场景使用座椅对应的物理地面脚点，不修改独立单角色视图的编排。

本视图始终是合成演示，不连接真实服务、不把真实 idle 当作摸鱼，也不声称采集接口提供了错误剧情、任务关系或最新用户请求。真实接入、显式绑定与请求增强仍在独立数据视图中；连接到实际宿主需要明确接线。

角色图集仍是高分辨率像素风动作原型。桌椅接触、路线和遮挡须经实际浏览器查看，自动化测试不能替代美术及空间验收；不宣称原生 48px、Electron 真机或真实 API 已完成验收。

主办公室两张子 Agent 独立桌纵向排列，座椅锚点为 (250, 600) / (250, 835)，尺寸系数 .756，与公共独立桌一致。桌面宽约 224.53，纵向间距 235，右侧通道 x=486 保留。主大桌、公共家具、世界与相机不变。物理子席只有 self-child-1 / self-child-2，配置中的第三个及以后子实例仍保留在详情与溢出名单，不改真实身份和绑定。
