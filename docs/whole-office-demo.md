# 整体办公室动作演示

默认视图把四套已有角色动作接入同一办公室平面；单角色动作检查及接入层数据视图继续单独保留。

## 空间与身份

- 自研 Agent 位于有明确边界的独立办公室。这个长期身份特权与任务中的 leader 身份不同。
- 办公室内另外显示最多三个模拟子 Agent 席位；超出人数以 +N 表示。子角色明确复用自研角色形象，不冒充新增独立人设。
- 其他三位角色位于普通办公区域。主从模式显式指定 ChatGPT 为本次模拟任务的负责人；平等模式使用共享协作桌，取消负责人层级。
- 切换布局不修改采集数据、角色身份或暂停意图。

## 动作与数据边界

同一条 26 秒演示时间轴编排进场、坐下、工作、摸鱼、Error、起身和退场，实际动作发生在各自工位。复用已认可素材与固定脚点坐起修正，提供暂停、重播和阶段选择，遵循减少动态效果偏好。进退场在同一个四秒阶段内按席位错峰释放，避免七个实例同时挤在入口；整体场景使用座椅对应的物理地面脚点，不修改独立单角色视图的编排。

本视图始终是合成演示，不连接真实服务、不把真实 idle 当作摸鱼，也不声称采集接口提供了错误剧情、任务关系或最新用户请求。真实接入、显式绑定与请求增强仍在独立数据视图中；连接到实际宿主需要明确接线。

角色图集仍是高分辨率像素风动作原型。桌椅接触、路线和遮挡须经实际浏览器查看，自动化测试不能替代美术及空间验收；不宣称原生 48px、Electron 真机或真实 API 已完成验收。
