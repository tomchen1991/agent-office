# 整体办公室动作演示

默认视图把四套已有角色动作接入同一办公室平面；单角色动作检查及接入层数据视图继续单独保留。

## 空间与身份

- 主办公室与公共区域固定共存，不再通过独立 / 主从 / 协作按钮替换家具。
- 主办公室有 1 个大工位及 1 张三人协作桌。自研 Agent 占大工位，模拟子 Agent 使用协作桌，最多展开 3 席，演示其余 2 个显示 `+2`。
- 公共区域有 3 张三人协作桌及 10 张独立办公桌。每席均有椅子、电脑与键盘，空席保留，不播放工作或异常。
- 23 个实体席位中，演示仅有原四角色与三个明确模拟子 Actor；未增加虚构身份填满空位。DeepSeek 位于公共协作桌 1，ChatGPT 和 Grok 位于独立工位，展示两类家具同时使用。
- 自研专属身份与任务中的 leader 不同。实际成员的物理席位来自显式配置或已配置成员顺序，不从厂商、主机或 collector role 推断。
- 默认恢复完整场景视图。逻辑画布收紧到 2250×1100，通过压缩行列空隙、调整实际桌椅 / 角色比例提高全景中的可见尺寸，不用相机放大替代布局调整。
- “适应全景”显示完整区域；可选“舒适近景”、100% 及区域定位仍保留，方便细看。缩放、平移和区域跳转都不改变身份、桌数或动作阶段。

## 动作与数据边界

同一条 26 秒演示时间轴编排进场、坐下、工作、摸鱼、Error、起身和退场，实际动作发生在各自工位。复用已认可素材与固定脚点坐起修正，提供暂停、重播和阶段选择，遵循减少动态效果偏好。进退场在同一个四秒阶段内按席位错峰释放，避免七个实例同时挤在入口；整体场景使用座椅对应的物理地面脚点，不修改独立单角色视图的编排。

本视图始终是合成演示，不连接真实服务、不把真实 idle 当作摸鱼，也不声称采集接口提供了错误剧情、任务关系或最新用户请求。真实接入、显式绑定与请求增强仍在独立数据视图中；连接到实际宿主需要明确接线。

角色图集仍是高分辨率像素风动作原型。桌椅接触、路线和遮挡须经实际浏览器查看，自动化测试不能替代美术及空间验收；不宣称原生 48px、Electron 真机或真实 API 已完成验收。
