# 整体办公室动作演示与共享场景

生产默认入口为 `PresenceOffice`，不是合成动作演示；开发环境 `?simulate=1` 打开 `LiveOfficeExample`。`WholeOfficeDemo`、`LifecycleDemo` 等组件仍保留，供单独动作检查，不把演示剧情当真实状态。

## 当前空间

- 世界 2250×1050，共 20 个固定实体席位。空家具不生成 Agent。
- 左侧上方主办公室：主工位 (250, 340)。左侧下方运维办公室：Auto-fix (190, 820)、DevOps (475, 820)。热点追踪在公共右上方 (1840, 300)。
- 公共区域：两张三人协作桌、十张独立桌，普通桌两排 y=570 / 795。
- 不再有主办公室内两张固定子桌。真实子 Agent 按分配规则使用空闲公共席；独立动作演示仍仅安排两个明确模拟子角色，坐公共第二张协作桌。
- 主身份不等于团队 leader，不按供应商或姓名推断任务关系。四类常驻身份按单实例设计；新增两类角色的后端接口与生产绑定留待后续，不在本轮实现。

## 比例、路线与相机

角色独立放大 25%，独立桌与共享桌横向收窄 10%，桌面高度不变。椅子与键盘保持已校准接触点；通过座位与脚底锚点变换保持坐下 / 起身端点连续，不修改批准 PNG。

公共主通道 x=780，左侧办公室连接通道 x=750。主办公室门洞 y=420–520、运维门洞 y=700–800，路线穿过各自中心；房间与门洞共享 `OFFICE_ROOMS` 几何。主办公室内部右侧路线收至 x=550，Auto-fix 闲逛转向点收至 x=165，避免贴墙。共享桌沿外缘接近各自座位。路径测试检查轴对齐与其他桌面包络避让，但不等于已完成浏览器像素级遮挡验收。

主办公室两扇窗、公共区域三扇窗放在可见上墙带，使用统一双格玻璃、细窗框和窗台。旧斜门框与玻璃墙装饰不再渲染，运维上墙仅保留大屏，不加房间标题。

默认无工具栏展示使用等比缩放，适配去掉顶部背景墙后的 2250×930 可见地面；不再把宽高独立拉伸。宽屏保留必要留白，窄屏提供等比滚动与区域定位。非展示模式仍有全景、近景、缩放、暂停等控制。

## 合成动作

同一条 32.5 秒时间轴编排进场、坐下、工作、摸鱼、Error、起身与退场；按座位错峰进退场。错误、协作关系和用户请求不得从演示剧情注入真实 DTO。支持暂停、重播、阶段选择、减少动态偏好。

摸鱼阶段为 11 秒。主 Agent 起身走向固定镰刀取放点，取起、旋转两圈、眨眼摆姿、放回并回座；GitHub Agent 坐着玩掌机后短逛回座，其余角色使用既有摸鱼帧。额外动作只在阶段入口锁定已加载素材，中途加载完成不跳入剧情。

镰刀旋转使用八方向帧，两圈后恢复握姿；身体底帧、固定握点与公共色板用于减少轮廓和色彩跳变。取放时始终只有一个道具所有者，底座持续存在。专属段 2600ms；取与放各 1 秒。精灵仍是高分辨率像素风原型，不宣称生产级逐像素一致。

## 真实状态表现

真实办公室独立使用规范化状态驱动：连接正常、数据新鲜、明确 idle 持续 5 秒后才允许专属空闲动作。这些只是空闲表现，不是采集活动记录。工作、等待、停止到来时先安全放回镰刀回座；过期、未知、断连冻结持有者及道具归属，恢复后安全收尾。素材失败不以其他角色代替。

公共席位满时，团队与子 Agent 进入无固定工位显示层：空闲沿公共底部通道游荡，工作时原地使用平板。平板素材待提供，当前站姿兜底；未知状态停止活动。可点击查看详情，不新增名单、工具栏或家具。详见 [超量角色](overflow-agents.md)。

## 夜间休息

主 Agent、Auto-fix、DevOps、热点追踪在可靠空闲且睡姿素材就绪时可伏桌休息。默认本机 22:00（含）至次日 07:00（不含），不表示服务停止；本机时钟不参与数据新鲜度计算。

工作到来先唤醒坐好；未知、过期或断连退出睡眠表现。减少动态使用中性静态姿势，暂停冻结时钟。非展示模式可以修改夜间窗口；设置仅当前视图有效，不写磁盘。

宿主可向 `LiveOffice` 传入 `nightRestConfig`（`{version:1, enabled:true, start:'22:00', end:'07:00'}`）、`wallClock` 与 `wallClockLabel`。动作演示支持明确标记的白天 / 夜间模拟，不冒充真实采集。

## 验证边界

合成状态、几何测试与 ReactDOM 挂载测试不能代替浏览器视觉验收、Electron 真机或真实 API 联调。布局调整后应同步维护几何、像素边界和 CSS 测试，不以旧坐标通过或单纯 DOM 存在宣称空间正确。
