# DevOps 大屏视觉占位

办公室墙面保留 DevOps 大屏的外观，永久显示“未连接服务数据源”。不提供虚构服务、服务健康状态或实时数据。

`DevopsMonitor` 仅接收 `compact?: boolean`（默认 `true`）。默认模式填满父容器，并使用容器宽度单位（cqw）缩放字体与间距；父容器须设置 `container-type: inline-size` 并提供宽高。非 compact 模式高度为 145px。

“查看详情”打开原生模态对话框。关闭按钮和 Escape 均可关闭并将焦点返回入口。详情渲染在办公室缩放容器之外，保证正常阅读尺寸。

组件不包含网络请求、轮询、数据契约或服务器配置。服务数据接入由用户自行实现，不属于此次素材交付。

测试覆盖纯视觉占位、两种尺寸模式、零网络请求、重复打开详情、关闭与焦点恢复。
