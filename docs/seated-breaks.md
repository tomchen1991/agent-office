# 三位工位闲暇动作

- DeepSeek：抱碗扒饭、满足咀嚼、放下饭碗。
- Grok：端杯碟、举杯啜饮、闭眼品茶、放回茶碟。
- ChatGPT：抱起薄荷绿盾牌、挡脸探头、眨眼、放低盾牌。

## 素材和时间轴

三张 `public/assets/demo/{deepseek,grok,chatgpt}/seated-break.png` 逐字节复制已批准图集，没有重绘或改动既有素材。每张 RGBA PNG 为 2048×1024、4×2 格、单格 512×512，沿用工位锚点 (250,355)。第 0、7 格与该角色原 `seated.png` 第 6 格逐像素相同。

`public/assets/demo/manifest.json` 保存原图 SHA-256、逐格名称、播放顺序、独立时长和原坐姿来源。`src/seatedBreak.ts` 使用相同帧序与毫秒时长；ChatGPT 循环 3890ms，DeepSeek 3840ms，Grok 4750ms。每轮首尾经过原坐姿，不使用站姿锚点，不新增 CSS 位移。生产构建沿用现有流程生成无损 WebP 交付副本。

## 接入行为

- 实时办公室只在已绑定人物、状态为明确且可靠的 idle、数据连接正常无错误、该角色专属图集加载完成、连续空闲 5 秒后播放。标签与 DTO 仍是“待机”，不把吃饭、喝茶或举盾当作采集事实。
- working、waiting、stopping、offline、unknown、过期或断连会立即取消坐姿道具动作；工作直接恢复敲键盘，离线沿既有离席流程处理。
- 实例/epoch、工位、角色或图集更换均不继承上一个动作。新角色重新等待 5 秒。
- 暂停冻结画面，但不会冻结状态和新鲜度更新。减少动态效果使用原坐姿静帧。原有常驻角色夜间休息与主 Agent 镰刀动作逻辑保持不变。
- 可选图集按可见角色低优先级加载，不阻塞基础坐姿首屏；失败时保留原坐姿。演示页在摸鱼阶段入口锁定已加载的专属图集，迟到的素材等下一次阶段或重播，不从动作中途加入。
- 整体办公室和单角色演示的摸鱼阶段均使用新动作。真实状态不播放演示的 Error 剧情。

## 验证与边界

新增测试直接解码 PNG，校验批准哈希、透明通道、尺寸、非空轮廓、脚点、锚点及首尾像素一致性；逐一验证帧时间边界与循环。纯状态和 React 挂载测试覆盖等待门槛、工作打断、暂停、减少动态、过期/断连、模型切换、素材失败以及两种演示入口。

浏览器验收使用同源静态构建与实际 `WholeOfficeScene`：检查整体演示播放、暂停、摸鱼到 Error 阶段切换，以及近景第 3、4、7 格的饭碗/筷子、茶杯、盾牌、桌沿遮挡与原坐姿复归。没有修改生产入口；临时检查按钮和页面不提交。此验收不覆盖移动端、Electron 或线上真实 presence 服务。

本轮只涉及三位工位动作、前端动画接线和测试说明。API、后端、核心传输 DTO、配置/bridge、presence WebSocket、生产入口和部署配置未修改。不包含游荡平板素材，不合并、不部署。

新动作仍有少量生成式轮廓变化；水平镜像也会翻转持物手与发饰。保留已批准素材的这些限制，不宣称逐像素手修生产动画。
