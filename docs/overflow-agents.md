# 超量 Agent 与平板素材接入

## 行为

20 个实体席位不变，公共容量为 16；显式团队席位优先，子 Agent 使用剩余公共席位。`childOverflowIds` 和 `teamOverflowIds` 合并渲染为无固定工位角色，不新增桌椅，不用同名或供应商猜身份。四种常驻身份仍按单实例设计，不增加重复角色处理或新的服务端 API。

- connected / fresh / idle：沿公共区域底部通道往返游荡。这是空闲表现，不是采集的真实位置。
- working：立即停止走路，在当前位置使用平板工作。
- waiting / stopping：原地站立，不虚构工作。
- unknown、过期或断连：原地中性站姿，不继续游荡或工作。
- 明确 offline 或不再属于溢出集合：移除无工位角色；获得座位后交由普通工位层显示，不生成双份角色。
- 暂停冻结时钟；减少动态效果使用静态帧。点击或键盘 Enter / Space 打开既有详情弹窗，不增加名单或工具栏。

位置以实例及 epoch 稳定初始化，名单排序变化不会重新排列已有角色。路线位于 x=870–2070、y=970/990/1010 的公共底部通道；该实现不做多角色碰撞避让，极大量溢出时仍可能重叠。精灵脚点、桌面及路线应继续做浏览器视觉验收。

## 给素材作者的约定

现有行走图集暂用于游荡，静止使用其第 0 帧；**平板素材尚未提供，工作时暂用原地站姿，不绘制假平板，也不借用坐姿工作图。**未知外观或素材未加载使用中性问号占位，保持可点击。

在 `src/demoAssets.ts` 对相应 `DemoCharacter` 添加可选 `tablet: DemoAtlas`：

- 建议透明 PNG，单帧 512×512，4×2 排列（可配置行列数）；每帧完整角色，包含手持平板，不带背景和桌椅。
- 所有帧从左至右、从上至下为连续工作循环，当前每帧 300ms；不要混入拿出 / 收起等一次性动作。
- 角色面向右；左向由显示层整体镜像。脚底锚点建议与 locomotion 一致：`{ x: 300/512, y: 470/512 }`；如实际不同，声明真实归一化锚点。
- 维持现有角色的身高、轮廓和配色，逐帧锁定脚底；禁止以其他角色图集代替。
- 推荐路径 `assets/demo/<角色>/tablet.png`。到图后先检查透明边界和脚点，再登记图集、资产清单及 WebP 构建输入；本次没有预注册不存在的文件。

可选平板图集后台加载，不阻塞普通角色。加载失败继续显示站姿；加载完成后原地切换平板图集，脚点不变。拿出 / 收起过渡暂未实现，后续若交付这类帧，需另行定义一次性动作时序，不能直接塞入当前循环。
