# Agent Office · DevOps 坐姿动作

基准：Agent Office 的 `public/assets/demo/devops/seated.png` 第 6 格（8 宫格，按行从左到右数）。沿用原 512 × 512 画布及坐姿锚点 (250, 355)，不按可见区域再次裁切。各帧为透明 RGBA PNG。文件按 01 → 04 播放。

| 目录 | 场景 | 建议帧时长（毫秒） |
| --- | --- | --- |
| inspect | 巡检／验证：视线扫过，轻点核对 | 230 / 220 / 130 / 400 |
| build-deploy | 构建／部署：短促敲键、确认、看进度 | 130 / 110 / 160 / 550 |
| rollback | 回滚：停一拍、单键按下、收手 | 260 / 240 / 120 / 420 |
| wait-human | 等待人工：手离键盘、放到腿上、抬眼 | 180 / 190 / 260 / 持续停留 |

等待动作只在进入 waiting 时播一次，然后保持第 4 帧。回滚动画表示执行中，不代表成功。unknown 继续复用静止坐姿并由 UI 显示「状态未知」；配置和通用执行继续复用原打字动作。
